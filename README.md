# Humaira Zeanova | Data Analyst Portfolio
Welcome to my personal portfolio website! This repository houses the source code for my portfolio, showcasing my projects in **Statistics, Deep Learning, Spatial Analysis and Time Series Analysis**.
🔗 **View Portfolio:** https://zeanovaa.github.io/portfolio/
## 📌 Overview
This portfolio is designed to be a clean, modern, and professional showcase of my technical skills and academic work. It features a responsive design, interactive elements, and detailed project documentation.
### Key Features
*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
*   **Interactive UI:** Includes 3D card flips, hover effects, and a custom cursor.
*   **Lightbox Gallery:** Clickable project images for detailed viewing.
*   **Smooth Navigation:** Sticky navbar with smooth scrolling to sections.
*   **Project Categorization:** Separated into "Featured Projects" and "More Projects" for better organization.
## 🛠️ Tech Stack
*   **HTML5**: Semantic structure and layout.
*   **CSS3**: Custom styling, CSS Grid/Flexbox, animations, and variables for theming.
*   **JavaScript (Vanilla)**: DOM manipulation, smooth scrolling, lightbox logic, and interactivity.
*   **Iconify**: vector icons for social media and tech stack.
*   **Google Fonts**: 'Outfit' and 'Playfair Display' typography.

## 🚀 Deployment
This project is ready to be hosted on **GitHub Pages** or **Netlify**.
### GitHub Pages Method
1.  Upload these files to a GitHub repository.
2.  Go to **Settings** > **Pages**.
3.  Select the `main` branch and `/ (root)` folder.
4.  Click **Save**.
